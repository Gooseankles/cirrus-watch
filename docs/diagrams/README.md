# Diagrams

The pictures in the docs, and the sources they are made from: `*.py` (Python with the
[diagrams](https://github.com/mingrammer/diagrams) library, MIT) for the building blocks, `*.mmd` (Mermaid) for
sequences and flows. `npm run diagrams` renders them; [CONTRIBUTING](../../CONTRIBUTING.md) has the details.

## Azure icons

The Azure icons in these pictures are Microsoft's, used under
[Microsoft's terms for architecture diagrams and documentation](https://learn.microsoft.com/en-us/azure/architecture/icons/):
shown as they are, with the product's name next to each, and never as an icon for Cirrus Watch itself. They are not
covered by this repo's license (AGPL-3.0-only), which covers the sources and everything else here.
